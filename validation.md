### 🔌 <font color="#8BE9FD">Hardware & Software Prerequisites:</font>

1. **Raspberry Pi (nearly optional)**    

   A Raspberry Pi is <strong>not mandatory</strong> for basic UI and handling tests.<br>However, evaluating the full scope of functionality requires access to a Raspberry Pi acting for instance as a router, smart home server, media center, or communication hub.

2. **Enabled SSH access on the Raspberry Pi**

   If you are using a fresh device image or SSH is disabled by default, open your Raspberry Pi terminal and run the following commands to enable and start the SSH service:

   ```bash
   sudo systemctl enable ssh
   sudo systemctl start ssh
   ```
3. **Network Connection Requirements**

   Both your mobile device and Raspberry Pi must be connected to the <strong>exact same Wi-Fi or local area network (LAN)</strong>. All communication occurs entirely locally within your private network without external routing.
